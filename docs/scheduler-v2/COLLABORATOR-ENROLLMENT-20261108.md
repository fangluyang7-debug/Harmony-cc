## 84. 图形接入、应用声明与调度盘（2026-11-08）

本轮按用户约定增加协调中心启动/停止页面、独立设备调度件、扫码配对与购物 App 的协同开关。实现保留 PlanningService 的正式派发入口；应用登记声明，运行时通过 SDK 提交任务，由规划器选择执行设备。

本机入口为根目录 `启动调度系统.cmd` 或 `npm run runtime:desktop`，依赖已构建的 Node.js 项目。中心运行在独立的 `data/desktop-<IP>` 目录，原 `data/lan` 保留。页面通过带会话令牌的回环控制接口启动、停止服务，收到真实 ready 后才显示运行状态。设备发现使用 UDP 7444 的公开地址提示；信任通过带证书的一次性邀请建立。二维码由固定版本 qrcode 1.5.4 在中心本地生成，PC 可导入同一邀请文件。

手机设备调度件负责保存设备身份和办理应用授权，购物 App 保存独立应用身份。首次打开协同开关自动提交内置工作流、输入输出契约和节点依赖声明。中心持久化声明，调度盘资源视图显示应用版本、能力与安装状态。ACTIVE 身份、设备在线和能力可执行是不同状态；缺失资源指标继续显示 UNKNOWN。

本轮未重跑 §83 的全部验收套件。主购物流程目前接入图片预处理，独立图像搜索入口接入图像编码；文字购物、账号和其他原有业务仍走原服务。图像编码还依赖真实模型、Python/CUDA 环境及可信评测套件。
