# 六位设备配对码

协调中心启动页点击「设备配对」，生成六位数字、短邀请链接和二维码。数字码保留前导零，最长五分钟有效，仅可兑换一次，中心重启后失效。中心按来源地址和全局窗口限制尝试次数。

Windows 启动页选择发现的协调中心，输入六位码，核对中心弹窗显示的 SHA-256 证书指纹后连接。发现失败时可以填写完整 HTTPS 中心地址。

鸿蒙的「设备连接面板」与「本机设备」入口均可输入六位设备配对码。第一次点击读取中心公开证书并显示指纹，核对后点击「确认指纹并连接」或「确认指纹并配对」完成兑换。邀请链接和 JSON 导入继续可用。

数字码兑换出完整的设备邀请后，沿用既有的设备凭据、空间切换、资源上报及额度流程。成员加入空间使用原有的八位加入码，具有独立的身份和权限流程。

数字码接口与证书引导用于局域网协调中心。部署代理模式不会提供此接口。首次获取的证书在核对指纹以前仅作为待确认信息，兑换请求在确认后的 TLS 连接中发送。

验证覆盖六位格式、期限、限流、并发单次兑换、错误指纹拦截、扫码配对后数字码失效，以及数字码兑换后完成原有设备注册。
