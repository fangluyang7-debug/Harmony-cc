# 鸿蒙设备调度件：任务槽

## 功能与入口

鸿蒙电脑打开“调度连接”，接入协调中心后，在左侧导航点击“任务槽”。入口与“扫一扫”“贡献上限”并列，是独立页面；贡献上限页不混入任务内容。

页面显示实际派发到本机的工作流步骤，包括能力名称、CPU/GPU 后端、阶段进度、接收至结束的本机耗时、输入输出字节数、工作流/节点/任务标识。没有进行中任务时显示“暂无任务”。下方保留最近五条完成或异常记录，避免毫秒级任务无法被评委看到。

进度条依次对应：收到任务 → 排队及准入 → 读取输入 → 本机计算 → 发布结果 → 本机完成。进度只来自实际执行边界，不按时间伪造递增，不代表整条业务流程完成百分比。没有细粒度计算进度的执行器，会停在“本机正在计算”，完成后进入发布阶段。成功表示本机结果已发布，不等于整个工作流或手机交付完成。

## 实现边界

- `apps/harmony/scheduler/src/main/ets/v2/host/NativeWorkSlots.ets`：最多 32 条本进程观察记录，不保存图片内容或凭据，不写数据库。
- `NativeAgent.ets`：仅在已验证的业务派发和实际执行阶段记录观察信息，校准不进入任务槽；不增加网络请求，不等待 UI，不更改分配、准入、预算或执行算法。
- `apps/harmony-agent/entry/src/main/ets/AgentRuntime.ets`：提供本机快照读取接口。
- `apps/harmony-agent/entry/src/main/ets/pages/WorkSlotPanel.ets`：页面可见期间每 250 ms 读取有界快照；并发任务分别展示，拒绝/失败不显示成功。
- `ConnectionLauncher.ets`：独立任务槽导航；手机原贡献页面不增加该面板。

记录随当前 NativeAgent 实例存在，不作为跨重启历史数据库。切换页面不会丢失观察记录；重启 App 或切换空间后不把旧记录冒充新空间任务。短任务可能直接从暂无跳到完成记录，不能通过人为拖慢计算来展示动画。

本轮不更改图片增强 App，也不重新安装手机图片 App；共享 HAR 仅新增只读观测，安装目标为鸿蒙电脑设备调度件。

## 任务阶段与输出用途（2026-11-14，修订）

SoleAI 的图片检索也会执行候选商品比价数据整理。执行器换算价格单位并生成顺序索引，手机将其存入 comparisonRank；默认相关度视图不因此变成价格排序视图。之前仅标为“价格排序”容易使用户误以为列表已经重排，因此任务槽现在分开显示工作流来源、实际业务阶段、实际执行说明与本机执行状态：

- 所属工作流：图片检索或文字检索；阶段：候选商品比价数据整理。
- 实际工作说明：校验商品价格、换算价格单位，生成价格顺序索引；手机切换“价格从低到高”时使用，默认相关度列表不因此重排。
- 图像相似度任务阶段：候选商品图像复核；实际工作说明：计算查询图与候选图的外观相似度，返回图片对分数。
- 只有本机实际收到 `image.visual-match.v1`，才能显示图像复核；不得把 catalog 执行展示成图像识别。

SoleAI 在排序任务的节点 ID 和工作流 ID 中保留业务来源；兼容传输将节点归一为 `compute` 时，仍可从工作流 ID 正确显示名称。旧任务没有来源标识时使用中性名称，不猜测是图片还是文字。此次仅调整标识和显示，计算输入、算法、预算、分配策略不变。
