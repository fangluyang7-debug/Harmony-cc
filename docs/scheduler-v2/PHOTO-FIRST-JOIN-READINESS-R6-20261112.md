## 定位结果

继续分析 R5 实测的首次授权 **28.0 秒**，不与同进程模式恢复的 1.2 / 2.2 秒混用。该次手机设备宿主在 17:19:57.437 创建 `image.crop.v1` 的 empty 参考用例，手机切到图片 App 后该用例没有被领取，最终以 `notRun: true`、执行时长 0 结算；用例预算为 15 秒。图片宿主直到 17:20:13.418 才开始第一个参考用例。

## 修复

`services/coordinator/src/remote-evaluation.ts` 在等待远程参考用例时，每 250 ms 最多检查一次未领取工作的宿主可用性。当同一设备实例、同一 ledger 的新鲜画像明确报告宿主进入后台，或所有者活动为 ACTIVE 时，使用事务内条件更新将仍为 QUEUED 的用例结算为未执行，及时释放物理设备校准队列。

- 仅处理确认未被领取的参考用例。已领取或取消中的执行仍等真实引擎结算，不能虚构完成。
- 缺失、过期、实例不匹配的画像不触发该优化；领取与退休竞争由数据库事务及状态条件保护。
- 不修改参考套件、质量标准、模型、业务预算；不缓存就绪布尔值，不读取或预处理用户所选照片。
- 后台宿主下次恢复后仍需完成自己的资格检查。图片 App 的绿色就绪继续来自真实资格。
