# 手机连接电脑调度件演示指南

## 先说结论

目前工程里有两条不同的链路，不能把它们当成同一个“手机直连调度件”：

1. **SoleAI/Harmony 原生 App 正式购物链路**：手机 App 访问 `https://cixin.zeabur.app`，购物任务在云端 Runtime 执行。电脑上的 `8765` 调度盘是手机实时状态的观测服务，手机通过 HDC 或同一局域网向它上报快照。
2. **Cixin Agent 电脑 Runtime 演示链路**：电脑运行 `Cixin/cixin-agent`，默认端口 `3200`，提供独立的演示 Web App 和电脑调度盘。它目前不是原生 SoleAI App 的默认后端，手机可以用浏览器打开它进行 Runtime 任务演示。

因此，下载并安装原生 HAP 后，最稳定的比赛演示连接方式是：

`手机 SoleAI App -> 云端 API -> 云端/设备执行 -> 电脑 8765 调度盘观测`

如果要演示 `cixin-agent` 本身，则使用：

`手机浏览器或电脑浏览器 -> 电脑 IPv4:3200/demo -> Cixin Runtime -> 电脑 IPv4:3200/dashboard`

## A. 原生 SoleAI App + 电脑实时调度盘

### 方式一：USB/HDC，最稳定

电脑启动 Harmony 监控服务：

```powershell
cd C:\path\to\Cixin\harmony-agent
npm install
npm run monitor:dev
```

记下终端显示的配对码。确认手机已连接并能被 HDC 识别：

```powershell
hdc list targets
hdc -t <设备ID> rport tcp:8766 tcp:8765
```

在手机 App 的“我的 -> 电脑实时监控”填写：

```text
地址：http://127.0.0.1:8766
配对码：电脑监控服务终端显示的配对码
```

在电脑浏览器打开 `http://127.0.0.1:8765`，输入同一个配对码。手机保持推送开启，电脑页面会显示真实手机状态、队列、策略和任务事件。

说明：`8766` 是手机通过 HDC 反向转发访问电脑 `8765` 的端口。App 里的 `127.0.0.1` 指手机自身，但经 HDC reverse 后会被转发到电脑。

### 方式二：同一局域网

查询电脑 IPv4：

```powershell
Get-NetIPAddress -AddressFamily IPv4 |
  Where-Object {$_.IPAddress -notlike '127.*' -and $_.PrefixOrigin -eq 'Dhcp'}
```

手机和电脑加入同一个可信 Wi-Fi 后，在 App 中填写：

```text
http://电脑IPv4:8765
```

电脑浏览器仍打开：

```text
http://127.0.0.1:8765
```

Windows 防火墙只允许专用网络访问。演示结束后关闭监控服务并关闭 App 的推送。

## B. Cixin Agent 独立电脑调度盘 + 手机浏览器

这条链路演示电脑 Runtime 的真实 CPU 执行、任务回执和调度盘，不替代原生购物 App。

在 PowerShell 中：

```powershell
cd C:\path\to\Cixin\cixin-agent
npm ci
powershell -ExecutionPolicy Bypass -File .\scripts\start-phone-demo.ps1
```

脚本会打印类似地址：

```text
电脑调度盘: http://192.168.1.20:3200/dashboard/
手机演示入口: http://192.168.1.20:3200/demo/
Runtime Token: ...
```

操作顺序：

1. 电脑浏览器打开调度盘地址，输入 Token。
2. 手机浏览器与电脑连接同一 Wi-Fi，打开手机演示入口，输入同一个 Token。
3. 手机演示页导入 `examples/vector-task.json`，提交任务。
4. 电脑调度盘按同一个 `runId` 显示真实执行节点、状态、耗时和回执。

如果手机打不开：

- 先在电脑浏览器确认 `http://127.0.0.1:3200/healthz` 返回 `{"status":"ok"}`。
- 确认手机和电脑在同一 Wi-Fi，而不是访客网络。
- 检查 Windows 防火墙是否允许 Node.js 在专用网络监听。
- 确认手机访问的是电脑 IPv4，不是 `127.0.0.1` 或 `localhost`。
- 端口被占用时修改 `config/phone-demo.example.json` 的 `port`，并同步使用脚本参数启动。

## C. 现场演示建议

推荐用双屏或分屏：

- 手机：SoleAI 原生 App，展示用户输入、图片购物和结果。
- 电脑左侧：`8765` Harmony 实时监控，展示手机状态。
- 电脑右侧：云端运行记录或 Cixin `3200` 调度盘，展示调度解释。

如果展示的是 Cixin `3200` 调度盘，应明确说“这是电脑 Runtime 的独立任务演示”；不要说成原生 SoleAI App 已经默认把任务直送到这台电脑。

## D. 交付边界

- 原生 HAP 的签名证书、密钥和本机 `build-profile.json5` 不放入共享包。
- Cixin `3200` 的 Token 只在启动终端显示，不写入源码。
- 调度盘未接入 NPU、功耗或云数据库时显示缺失状态，不使用静态数字冒充实测。
- `cixin-agent` 当前可直接演示 `catalog.vector_search` 的真实 CPU 任务；它不是完整图片识别模型服务。
