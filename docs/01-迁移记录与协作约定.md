# 迁移记录与协作约定

日期：2026-09-18。

## 迁移范围

源：同 Git 仓库 `shopping-assistant` 工作区；目标：`harmony-agent`。源提交与逐文件哈希见根目录 `migration-manifest.json`，设计快照包含前轮尚未提交的 V2 文档。

复制了后端 src、Prisma schema／迁移、测试、后端辅助脚本、Web 调试代码和页面、Python Worker 代码、无密钥配置示例与锁文件。保留整个购物后端是因为会话、图像、索引和商品池之间已有依赖，直接只摘 Runtime 会造成接口和模块缺失。

排除：`.env`、node_modules、虚拟环境、数据库、模型权重、批量商品数据、Android／Flutter／Capacitor 工程、构建产物、历史截图素材、发布／批量上传脚本和非代码异常文件。引用缺失样例的手动 HTTP 测试文件也未复制。

## 鸿蒙目录内的初始改动

- 根 workspace 名称及服务／Web 包名独立，移除不需要的 Capacitor 根依赖并同步锁文件。
- API 默认 3100，Web 5180，预览 4180，图像 Worker 7801；数据库示例采用独立文件名。
- Vite 的 envDir 指向本目录，修复新目录前端配置加载；所有调试页默认请求新 API 端口。
- 首页改为鸿蒙开发入口，去除旧 Android 展示页及图片依赖；保留业务调试页面。
- 原生应用目录预留，但未生成 SDK／签名／发布配置。
- 原 Runtime 的模型规划、真实执行和硬件适配缺口保持如实标注，不伪造可运行能力。

## 协作规则

两个目录是独立文件副本，不共用配置、node_modules、数据库或源码软链接。鸿蒙变更只编辑本目录；通用修复若需同步到另一项目，应明确选择文件并分别验证，避免直接覆盖整个目录。

仍使用外层 `Cixin` Git 仓库，本次未建立新远程、提交或推送。按文件夹选择提交范围，避免将另一比赛尚未审阅的改动一起提交。未来如需独立仓库，再单独迁移 Git 历史或初始化远程。

此芯方案阅读入口：`reference/cix/26-参赛作品设计-通用端云协同Runtime.md` 和 `reference/cix/27-端云模型分工与项目架构图.md`。这些是来源资料，不是已完成的鸿蒙功能说明。

2026-09-18：在新目录独立安装依赖并生成 Prisma Client 后，`api:build`、`web:build` 通过；单元测试 15 组、145 项全部通过。Web 首次构建受到 Windows 沙箱路径访问限制，获准在沙箱外重跑后通过。迁移源文件哈希逐项核对无变化。

未进行 HarmonyOS 真机／HAP 构建、端侧模型、云接口、完整购物链路或端到端数据库测试。未复制或创建生产数据库，实际启动所需配置仍由本目录独立提供。
