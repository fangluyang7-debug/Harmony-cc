## 3. 已发现的最小闭环风险

1. **演示开关与设备状态是前提。**购物派发默认关闭；只有 `PHONE_DISPATCH_EXPERIMENT_ENABLED=true`、`PHONE_DISPATCH_SHOPPING_DEMO_ENABLED=true`、B 已配对且持续在线轮询时才选择 B。B 不在线或失败时回到云端裁剪。服务端会核验回传 JPEG 的尺寸与摘要；目前 B 必须让验收页保持前台，尚不是后台常驻执行器。
2. **P1：图片链路存在间歇性失败。**此前同一已知商品图出现过前置 `POLICY_REJECTED / REMOTE_UNAVAILABLE`，合成图出现过 `DEPENDENCIES_NOT_READY:embedding` 与 `RUNTIME_EXECUTION_FAILED`。当前健康探针全绿，但仍需对同图多次运行才可评估稳定性。
3. **P1：新部署异常路径未全面重跑。**取消、物理停止确认和撤销已有旧版真机证据，当前修订的单设备在途租约保护有本地回归；线上新版本只复验成功派发和未授权拒绝。没有把旧证据冒充新版本全量回归。
4. **P2：性能与恢复条件不足。**当前受控购物跨机正向样本为一次。没有同条件多轮端到端样本；Wi-Fi 真断网、进程被系统杀死、模型质量抽样及设备硬件证明均未纳入本次最小验收，不作相应性能、安全或可用性承诺。

## 4. 作品演示建议与验收门槛

当前可演示：A 的文字购物；再由 A 选已知目录黑色跑鞋图，B 在“双机派发验收”页保持前台轮询并显示 `B 购物图片回执：COMPLETED`，A 返回同图相关商品，并在“我的”页显示本次云端运行 `completed / settled`。电脑调度盘可辅助观察同次 A 购物任务。演示前确认两机联网、Zeabur Running、两项演示开关已启用、A/B 配对有效、B 屏幕亮且验收页在前台。合成向量任务可作为派发机制的单独说明，不需与购物任务混称。

本轮已满足“购物图片的一段计算真实派给 B”的受控演示门槛。若要宣称可重复、通用或生产可用，仍需导出同一 `runId` 的服务端 placement 审计，完成多轮正向/失败回退、B 后台与断网恢复、开放图片召回和端到端时延对照；这些不属于本次最小闭环通过结论。
