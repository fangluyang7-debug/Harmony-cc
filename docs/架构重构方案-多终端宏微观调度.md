# 智调鸿枢架构重构方案 v2 - 多终端宏微观调度

## 一、核心理念纠正

### 错误理解 ❌
- 手机是特殊的,需要特殊对待
- 购物是主业务,其他是扩展
- 设备注册需要新建一套系统

### 正确理解 ✅
- **手机 = 一个普通终端设备** (与Worker/Edge地位平等)
- **购物 = 一个测试App** (验证调度系统的业务载体)
- **终端可插拔** (动态上线/下线,自动发现)

### 修改3: 云端创建统一派发服务

**新文件**: `services/api-server/src/core/runtime/unified-dispatch.service.ts`

```typescript
import { Injectable, Logger } from '@nestjs/common';
import { DeviceDispatchService } from './device-dispatch.service';
import { PhoneDispatchService } from '../../modules/runtime/phone-dispatch.service';
import { WorkflowPlacementPlanner } from './workflow-placement-planner';

interface DispatchContext {
  capability: string;
  ownerId: string;
  budgetMs: number;
  // ... 任务上下文
}

@Injectable()
export class UnifiedDispatchService {
  constructor(
    private readonly deviceDispatch: DeviceDispatchService,
    private readonly phoneDispatch: PhoneDispatchService,
    private readonly planner: WorkflowPlacementPlanner
  ) {}
  
  /**
   * 统一派发入口 - 根据capability查询所有终端并选择最优
   */
  async dispatch(context: DispatchContext): Promise<any> {
    // 1. 收集所有可用终端
    const candidates = await this.gatherCandidates(context);
    
    // 2. 调用规划算法
    const decision = this.planner.plan({ 
      nodes: [/* 根据capability构建 */],
      candidates 
    });
    
    // 3. 根据决策派发到对应终端
    const target = decision.suggestion?.deviceId;
    
    if (target === 'cloud-runtime') {
      return this.executeOnCloud(context);
    } else if (target.startsWith('phone-')) {
      return this.phoneDispatch.dispatch(target, context);
    } else if (target.startsWith('worker-')) {
      return this.deviceDispatch.dispatch(target, context);
    }
  }
  
  private async gatherCandidates(context: DispatchContext) {
    const candidates = [];
    
    // Cloud总是可用(兜底)
    candidates.push({
      deviceId: 'cloud-runtime',
      capability: context.capability,
      // ... 云端参数
    });
    
    // 查询Worker (从descriptor协议)
    const workers = await this.deviceDispatch.queryWorkers(context.capability);
    candidates.push(...workers);
    
    // 查询在线Phone (从配对服务)
    const phones = await this.phoneDispatch.queryPhones(context.capability);
    candidates.push(...phones);
    
    return candidates;
  }
}
```

```typescript
async dispatch(capability: string, context: any): Promise<any> {
  // 1. 获取支持该capability的Worker列表
  const workers = await this.queryWorkers(capability);
  
  // 2. 调用planner选择最优

  // 3. 执行
  return this.executeOnWorker(decision.target, capability, context);

/**
 * 查询支持特定capability的Worker
 */
async queryWorkers(capability: string): Promise<WorkerDescriptor[]> {
  const devices = this.devices(); // 现有方法
  const results = [];
  
  for (const device of devices) {
    const descriptor = await this.call(device, 'descriptor', ...);
    if (descriptor.capabilities.includes(capability)) {
      results.push({ deviceId: device.deviceId, descriptor });
    }
  }
  
  return results;
}
```

### Phone动态上报

**新文件**: `apps/harmony/entry/src/main/ets/services/DeviceProfileReporter.ets`

```typescript
export class DeviceProfileReporter {
  private timer: number = -1;
  
  start() {
    this.report(); // 立即上报
    this.timer = setInterval(() => this.report(), 30000);
  }
  
  private async report() {
    const state = globalThis.schedulerRuntime?.getDeviceState();
    
    await fetch(cloudUrl + '/api/v1/runtime/phones/register', {
      method: 'POST',
      body: JSON.stringify({
        deviceId: 'phone-' + deviceInfo.udid,
        capabilities: this.discoverCapabilities(),
        resourceSnapshot: {
          thermalLevel: state.thermalLevel,
          batteryPercent: state.batteryPercent,
          availableMemoryMb: state.availableMemoryMb
        }
      })
    });
  }
  
  private discoverCapabilities(): string[] {
    // 检查本地是否有模型文件
    const caps = ['shopping.image.search.v1']; // 基础能力
    
    if (hasLocalEmbeddingModel()) {
      caps.push('image.embedding.v1');
    }
    
    return caps;
  }
}
```
