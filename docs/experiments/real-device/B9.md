5. 运行任务时切到系统桌面或其他 App：停止新准入，已准入的可取消任务发出 YieldNotice；在原生执行真正停止/完成前保留资源。观察任务、画像和协调者记录，记录后台限制，不申请未经验证的持续后台能力。
6. 返回前台：仅在本机贡献开关仍启用时恢复贡献。验证手动关闭贡献后，即使切换前后台也不会重新开启。
7. 专用测试 App 强制停止再启动，核对关系型数据库、原 fence、未确认 outbox 与状态查询；旧 RUNNING 不得自动重执行。ACCEPTED 只有持久化的未开始证明才能结算取消。不要以杀进程本身推断所有资源已释放。
8. 断开/恢复网络，核对同一 holder 的额度续期、占用对账、签名篡改拒绝和凭证撤销。导出业务 PLAN/OFFER/QUEUE/ADMIT/LOAD/EXECUTE/PUBLISH 追踪，核对真实 snapshotVersion；缺少 SDK 根跨度时仍标计量不完整。
