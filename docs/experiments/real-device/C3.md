# C3 鸿蒙来源 SDK 真机验证

状态：待真机，未执行。开发基线 HarmonyOS 6.0.2 / API 22。

先按 C7a 准备已签名的 SoleAI 最小裁剪入口和同一局域网 PC，使用独立 App 注册凭据。手机来源 App 与 PC 的可用能力须通过同一参考评测；能力未就绪不能手工跳过资格检查。保留本地 v1 入口，断线新业务不进入 v2 账本。

1. 手机来源 App 在前台提交真实裁剪，记录 PlanningService 决策及实际执行目标；使用允许的执行配置/负载和真实链路，分别形成手机执行与 PC 执行的合法场景。目标切换必须来自规划器，不能修改数据库伪造目标。若 PC 尚无裁剪资格，如实记录待补，不能用文本任务冒充裁剪验收。
2. 本地选择时，确认输入及结果未上传协调者；远端选择时，确认授权传输、制品哈希、结果解码与 committed 回执。未经授权的另一个 App 不能取得输入或结果。
3. 提交后取消，持续记录 CANCEL_REQUESTED 与资源占用，只有真正停止后才出现结算；重复取消不得重复释放。分别测试执行前、执行中及结果已提交后取消。
4. 断网/应用重启后核对原 attempt、账本、结果与结算，未知任务不得自动改为本地重做。新任务走原 App 本地调度时不得写入 v2 任务账本。
5. 固定服务适配器使用来源 App 私有业务登录态；记录服务侧请求、任务和回执关联，检查协调者元数据中没有长期业务凭据。

记录手机系统/签名/SDK、PC版本/网络、输入输出哈希、各目标计划与实测分段、取消/恢复故障注入、回执和未结算占用。没有真实记录之前不标记完成。
