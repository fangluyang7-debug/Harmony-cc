## 已接入的鸿蒙 CPU 模型装载路径

当前适配器支持一个 NHWC、uint8、形状为 [1, size, size, 3] 的 RGB 输入张量，输出为一个 float32 向量。图片按固定宽高解码，RGB 通道按行排列。模型图负责该模型所需的归一化与其他预处理，宿主对输出向量做 L2 归一化。转换制品必须按这项输入契约生成，特定裁剪、缩放或色彩规则无法满足时须用独立模型空间，或先扩展并验证预处理。执行后端固定为 CPU。

构建前准备同一份受信编码 suite、转换得到的 MindSpore Lite 模型及一份转换描述 JSON。suite 的 executorIds 需要包含 harmony.image.cpu.v1。转换描述的 suite、modelFile 为相对该 JSON 的文件路径，convertedSha256 为转换制品实际 SHA-256，preprocessVersion 须与套件完整模型清单一致，inputLayout 填 RGB_UINT8_NHWC_RESIZE，size 填实际输入边长。源权重摘要与转换制品摘要分别校验。设置 HARMONY_IMAGE_ENCODER_CONFIG 为转换描述路径，然后使用仓库的 HAR 和 HAP 构建命令。未配置时，应用只装入已有能力包。

构建时校验资源及摘要，执行时再次检查转换制品、请求模型空间、张量类型和维度，参考评测和业务使用同一执行代码。软件边界测试使用替身推理张量验证 RGB 顺序、归一化和错误摘要拒绝，不能作为 X6 的模型选择或质量验收。转换模型、真实参考图像与独立检索集由后续 X6 实验冻结后提供。
