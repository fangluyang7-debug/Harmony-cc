# 三台物理设备局域网验收 · 2026-11-07

本轮已跑通签名安装、设备入组、局域网认证通信、三端实际计算、自动调度、结果校验和代理重启恢复。**功能链路通过本轮检查；批量文档统计未获得协同加速，不能作为“团队比最快单机更快”的路演证据。**

## 环境与边界

- 分支 `codex/real-device-acceptance`，提交基线 `f652683` 加当前工作树。未修改协作者分支，也未部署 Railway。
- Windows 同时运行局域网协调者与 CPU 代理；鸿蒙电脑和手机安装同一原生代理。三台都是真实物理设备，空间域为 `REAL`。
- 三端位于同一 WLAN 子网。协调者实际观察到来自两台鸿蒙设备 WLAN 地址的 TCP 连接；未配置 USB 端口转发。USB 仅用于安装、启动与诊断。
- 两台鸿蒙设备实际系统 API 均为 24，本轮使用 HarmonyOS 6.1.1 / API 24 SDK 构建及开发者调试签名。API 22 正式基线仍未验收，不能由此次结果替代。
- Windows 协调端口 7443、数据端口 7444。原生代理主动连接协调者，无入站数据服务；本轮不宣称三设备全互联直传。未更改系统防火墙规则。
- CPU 贡献配置每台最多 3 槽位、512 MiB 内存。来源 App 使用独立身份，通过正式 SchedulerSdk / PlanningService 派发。

包哈希及设备逻辑 ID 见 [环境记录](THREE-DEVICE-ENVIRONMENT.json)。签名密钥、账户口令、设备邀请与认证凭据仅留在忽略目录，未纳入本报告。

## 性能结果

每批为相同的 12 份合成文档，并发数固定为 3，三个单设备目标和团队自动模式轮换顺序，重复 3 轮。每个文档都有独立算术答案；计时包括输入注册、传输、调度、执行、轮询与完整结果返回。所有模式均通过协调者，单设备模式不是无框架开销的原生基准。

| 模式 | 三轮批次中位耗时 |
| --- | ---: |
| Windows 单设备 | 17.73 秒 |
| 鸿蒙电脑单设备 | **15.41 秒** |
| 鸿蒙手机单设备 | 17.33 秒 |
| 团队自动选择 | 18.10 秒 |

团队相对最快单设备速度比为 **0.851**，即批次用时约多 **17.5%**，报告结论 `NO_SPEEDUP`。36 个团队模式任务中，35 个选中 Windows，1 个选中鸿蒙电脑；没有自动选中手机。手机的计算能力由定向单设备与同批检查验证，不得将这 36 项描述为三台自动分担。

已有阶段测量中，EXECUTE 中位数约为 Windows 161.5 ms、鸿蒙电脑 44.5 ms、手机 43 ms；这不是完整结果延迟，PC 阶段还包含工作进程启动开销。原生执行阶段记录只覆盖部分任务（电脑 32/37、手机 30/36），跨设备时钟间隙仍为 UNKNOWN，不能拼接成完整关键路径或把未解释时间归因给网络。见 [阶段覆盖与中位数](THREE-DEVICE-PHASES.json)。

当前证据支持优先检查：原生阶段记录完整性、输入规模与执行估计的匹配、通信/持久化/准入/轮询开销。随后选择计算占比更高的真实 CPU 任务重新做相同口径的对照。不要通过假成本、强制分配或删掉失败/慢样本制造加速结论。

## 本轮修复与仍待验证

原生代理将瞬时重试错误写入主状态后，即使连接已经恢复也可能一直显示该错误。本轮分离“当前连接状态”和“最近诊断”，周期性按实际连接、贡献与能耗状态刷新。更新后的手机页面实际读取到“已连接 · 前台贡献”，历史诊断仍保留。API 24 HAR、签名 HAP 重建通过；连接重试平台替身测试 3/3 通过；两台物理设备覆盖安装和任务复测通过。性能对照使用更新前的包，更新仅修改状态显示。

校准/运行过程中记录到 `EVALUATION_SETTLEMENT_UNKNOWN`、`ALLOTMENT_REJECTED` 与 `ALLOTMENT_ACK_REJECTED` 等瞬时诊断；后续能力准入和本轮任务均完成。原始日志留存，不把“最终通过”描述为全过程没有重试或异常。

仍待验证：正式 API 22 构建、扫码交互、Wi-Fi 物理断连和在途恢复、长时间温控/后台行为、更完整的跨时钟追踪，以及能稳定证明协同加速的演示负载。此次物理设备结果也不能证明所有鸿蒙型号均兼容；实现未设置型号白名单。

本机完整证据与私有运行配置位于 `.test/real-device-20261107`，协调中心和 Windows 代理继续运行。原生应用须保持前台贡献。重新运行对照时使用新的报告文件名，保留已有样本；请勿将该目录整体提交或分享，目录内包含本地测试账户和设备凭据。

收尾时两台鸿蒙设备已锁屏，画像转为 BACKGROUND / WAITING_WINDOW，手机随后显示离线。HDC 启动应用返回 10106102（屏幕锁定，不能自动解锁）；未尝试绕过锁屏。继续演示前须由使用者解锁并让代理保持前台。这是验收结束后的状态，不应把之前的成功结果表述为两台设备目前仍可持续接单。
